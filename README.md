# Electric Vehicle Winter Range — Frontend

Frontend-приложение для работы с электрическими нагрузками электромобиля в зимних условиях.

Проект разработан в рамках лабораторной работы №5 по дисциплине «Разработка интернет-приложений».

## Технологии

- React
- TypeScript
- Vite
- React Router
- React Bootstrap
- Bootstrap

В лабораторной работе используются mock-данные. Взаимодействие с backend, PostgreSQL и MinIO/S3 на данном этапе не выполняется.

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск приложения в режиме разработки:

```bash
npm run dev
```

Проверка исходного кода:

```bash
npm run lint
```

Production-сборка:

```bash
npm run build
```

После запуска приложение доступно по адресу:

```text
http://localhost:5173/
```

## Страницы приложения

В лабораторной работе доступны две страницы.

### Лента

URL:

```text
/
```

Страница отображает карточки электрических нагрузок автомобиля.

Для каждой нагрузки отображаются:

- название;
- описание;
- категория;
- приоритет;
- потребляемая мощность;
- количество отметок «Нравится»;
- изображение;
- видео.

Карточки формируются из коллекции mock-объектов.

### Плитка

URL:

```text
/tile
```

Страница отображает электрические нагрузки в виде плитки карточек и содержит фильтрацию.

Доступны следующие поля фильтрации:

- поиск по названию;
- выбор категории;
- максимальная потребляемая мощность.

Также отображается количество найденных нагрузок.

Кнопка **«Сбросить фильтры»** очищает все установленные условия фильтрации.

## Навигация

В нижней навигационной панели находятся четыре пункта:

1. **Лента** — доступна.
2. **Добавление** — недоступна в лабораторной работе №5.
3. **Плитка** — доступна.
4. **Вход** — недоступна в лабораторной работе №5.

Маршрутизация реализована с помощью `react-router-dom`.

## Mock-данные

Тестовые данные расположены в файле:

```text
src/shared/data/mockLoads.ts
```

Описание структуры электрической нагрузки расположено в:

```text
src/entities/electric-car-load/model/types.ts
```

Основные поля объекта электрической нагрузки:

- `id` — идентификатор;
- `name` — название;
- `description` — описание;
- `category` — категория;
- `power_draw_w` — потребляемая мощность в ваттах;
- `priority` — приоритет;
- `image_url` — путь к изображению;
- `video_url` — путь к видео;
- `like_count` — количество отметок «Нравится».

## Изображение и видео по умолчанию

Если у электрической нагрузки отсутствует изображение, используется:

```text
/public/default.jpg
```

Если отсутствует видео, используется:

```text
/public/default.mp4
```

Для изображения также реализована обработка ошибки загрузки. Если исходное изображение не удалось загрузить, автоматически устанавливается `default.jpg`.

## Фильтрация

Фильтрация реализована на странице плитки.

Используются три состояния:

- `search` — строка поиска;
- `category` — выбранная категория;
- `maxPower` — максимальная мощность.

Карточка отображается только в том случае, если одновременно выполняются установленные условия фильтрации.

## React Hooks

В проекте используются следующие хуки React:

### useState

Используется для хранения текущих значений фильтров:

```text
search
category
maxPower
```

### useEffect

Используется для установки заголовка страницы плитки после рендеринга компонента.

## Props

Данные конкретной электрической нагрузки передаются из страницы в компонент карточки через `props`.

Компонент:

```text
LoadCard
```

получает объект:

```text
load: ElectricCarLoad
```

После этого данные объекта используются для формирования содержимого карточки.

## Особенности лабораторной работы №5

В рамках лабораторной работы реализованы:

- функциональные React-компоненты;
- две доступные страницы;
- четыре пункта навигационного меню;
- маршрутизация;

- вывод коллекции mock-объектов;
- передача данных через props;
- использование `useState`;
- использование `useEffect`;
- фильтрация карточек;
- изображение и видео по умолчанию;
