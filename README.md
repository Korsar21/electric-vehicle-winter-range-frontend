# Electric Vehicle Winter Range — Frontend

Веб-приложение для работы с электрическими нагрузками автомобиля, влияющими на энергопотребление электромобиля зимой.

## Лабораторная работа №6

Завершение пользовательского интерфейса React: подключение Go API, управление состоянием через Redux Toolkit и взаимодействие с сервером через Axios.

### Реализованные возможности

- Аутентификация пользователя и выход из системы; переключение пунктов меню «Вход» и «Выход».
- Получение электрических нагрузок из веб-сервиса в виде плитки и ленты.
- Поиск по названию, фильтрация по категории и максимальной мощности.
- Сохранение фильтров при переходах между страницами и их сброс при выходе.
- Создание черновика и публикация электрической нагрузки с изображением и видео.
- Обновление предпросмотра после выбора файлов.
- Постановка и снятие лайков, удаление собственных нагрузок.
- Индикаторы загрузки, обработка ошибок и блокировка повторных действий во время запросов.
- Гостевой просмотр mock-данных при недоступности бэкенда.
- HTTPS и проксирование запросов к API и MinIO через фронтенд.

### Страницы приложения

| Страница | Маршрут | Назначение |
|---|---|---|
| Лента | `/` | Просмотр выбранной или следующей электрической нагрузки |
| Плитка | `/tile` | Список нагрузок, поиск и фильтрация |
| Добавление | `/add` | Работа с черновиком, выбор файлов и публикация; доступно после входа |
| Аутентификация | `/auth` | Вход существующего пользователя |

Регистрация во фронтенде ЛР6 не реализуется.

### Управление состоянием

Redux store содержит три раздела:

- `auth` — состояние входа и сведения о пользователе;
- `filters` — строка поиска, категория и ограничение мощности;
- `electricCarLoads` — список, элемент ленты, черновик, загрузка и ошибки.

Фильтры изменяются синхронными actions. Операции с электрическими нагрузками выполняются через `createAsyncThunk`.

JWT сохраняется в `localStorage`, а состояние авторизованного интерфейса — только в Redux. После F5 интерфейс возвращается в гостевое состояние, при этом JWT остаётся в браузере. Автоматическое восстановление входа намеренно не используется по условию лабораторной работы. При успешном выходе токен удаляется, фильтры и частные данные сбрасываются.

### Взаимодействие с API

Семь предметных методов генерируются из Swagger с помощью `swagger-typescript-api`. Сгенерированный Axios-клиент вызывается внутри thunk.

| HTTP | Маршрут | Назначение |
|---|---|---|
| GET | `/api/electric-car-loads` | Список с параметрами `search`, `category`, `maxPowerW` |
| GET | `/api/electric-car-loads/feed` | Первая, выбранная или следующая нагрузка |
| GET | `/api/electric-car-loads/draft` | Черновик текущего пользователя |
| POST | `/api/electric-car-loads` | Создание черновика; `multipart/form-data` с `name`, `image`, `video` |
| PUT | `/api/electric-car-loads/{id}` | Заполнение и публикация черновика; JSON |
| DELETE | `/api/electric-car-loads/{id}` | Логическое удаление собственной нагрузки |
| POST | `/api/electric-car-loads/{id}/like` | Постановка или отмена лайка: `like=1` / `like=0` |

Две операции выполняются вручную через Axios, без кодогенерации и thunk:

- `POST /api/users/auth` — вход;
- `POST /api/users/logout` — выход.

Всего используются **девять разных операций API**. Сценарий публикации новой нагрузки включает создание черновика POST-запросом и последующую публикацию PUT-запросом.

### Технологии

React 19, TypeScript 5.9, Vite 8, React Router, React-Bootstrap, Bootstrap, Redux Toolkit, React Redux, Axios, swagger-typescript-api.

Серверная часть: Go, Gin, GORM, PostgreSQL, Redis, MinIO и Swagger.

## Запуск

Бэкенд и хранилища должны быть запущены согласно настройкам backend-проекта.

```bash
npm ci
npm run setup:https
npm run dev
```

Приложение доступно по адресу **https://localhost:3000/**. После первоначальной подготовки для обычного запуска достаточно `npm run dev`.

`setup:https` создаёт локальный сертификат в `.local/https/`; доверие публичному сертификату при необходимости настраивается пользователем вручную. Закрытый ключ и локальные сертификаты в репозиторий не включаются.

В `vite.config.ts` настроены маршруты:

- `/api/` → Go API;
- `/s3/` → MinIO;
- `/api-static/` → прежние статические файлы Go-сервиса.

В текущем окружении API доступен по `http://[::1]:8080`, MinIO — по `http://127.0.0.1:9000`. При переносе проекта адреса проверяются в конфигурации прокси. Для production-развёртывания требуется собственный обратный прокси с аналогичными маршрутами.

## Кодогенерация

Swagger читается из соседнего каталога `../electric-vehicle-winter-range-backend/docs/swagger.json`.

```bash
npm run generate-backend-types
```

Результат: `src/shared/api/generated/Api.ts`. Сгенерированный файл не редактируется вручную.

## Проверки

```bash
npm run lint
npm run build
```
